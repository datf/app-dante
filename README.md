# Home Assistant App: Dante

Dante is a robust, flexible, and highly reliable SOCKS proxy server (supporting both SOCKS4 and SOCKS5). This app allows you to run a SOCKS proxy directly on your Home Assistant instance, enabling you to route traffic from other devices or networks securely through your Home Assistant host.

## Documentation

For the full app documentation, including detailed installation instructions, configuration options, and advanced `sockd.conf` setup, please refer to the documentation file:

**[Read the Full App Documentation here](dante/DOCS.md)**

## Installation Quick Start

This app is available through a custom repository. To install it:

1. Follow [this link](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fdatf%2Fhassio-addons) to add the repository and click Add.
2. Search for **Dante** and click Install.

_Please read the [full documentation](dante/DOCS.md) before starting the app to ensure it is configured securely._
